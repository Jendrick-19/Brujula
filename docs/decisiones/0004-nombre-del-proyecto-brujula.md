# 0004. Nombre del proyecto: Brújula

- Estado: aceptada (pendiente de comprobar disponibilidad)
- Fecha: 2026-10

## Contexto
El nombre provisional "CuidaEquipo" era descriptivo pero poco memorable.

## Decisión
El proyecto se llama **Brújula**: orienta al personal en el convenio, la normativa y los protocolos, y encaja con el asistente con IA que cita la fuente. Identificador técnico: `brujula` (sin tilde) para repositorio, base de datos, contenedores y paquetes.

## Pendiente
Comprobar que no exista una app o marca registrada con el mismo nombre en el sector (Google Play, App Store, OEPM) y valorar dominio y nombre de organización en GitHub.
